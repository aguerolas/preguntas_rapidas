# executive

No new functionality is being implemented for the EDITRAN product as part of this initiative. The changes are focused exclusively on migrating the CCE application from a PC to dedicated servers and automating process execution. EDITRAN will operate on dedicated servers for each entity (CSF and SBP), hosted on Windows Server 2019, with access restricted to Operators and Security personnel through individual domain credentials. Communication with the CCE will take place exclusively through Bancared, using only the IP addresses and ports that have been registered and authorized by the regulator. The TDES-3 confidentiality algorithm and the RSA 4096 authentication scheme are defined by the regulator’s own protocol and cannot be configured unilaterally by the entity. The IS&Advisory team assumes that the information provided for this assessment (ARB, TDD, emails from the EDITRAN support team and application security reports) is accurate and corresponds to the development carried out within the defined scope
